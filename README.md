# 23CSE301 — Machine Learning Capstone Project

## Overview

This repository contains the Machine Learning Capstone Project for the course **23CSE301 — Machine Learning**, Academic Year 2026–2027.

The project applies machine learning techniques to three tracks: **Regression, Classification, and Clustering**. It covers data preprocessing, exploratory data analysis, feature engineering, model implementation, evaluation, comparison, hyperparameter tuning, and visualisation.

## Project Tracks

### 1. Regression

Regression techniques are implemented to predict continuous numerical values.

The track includes:
- Data preprocessing and feature engineering
- Implementation of 10 regression algorithms
- Model evaluation and comparison
- Hyperparameter tuning and cross-validation
- Residual and prediction visualisations

**Evaluation metrics:** R² Score, RMSE, and MAE.

### 2. Classification

Classification techniques are implemented to predict class labels using the Human Activity Recognition dataset.

The track includes:
- Data inspection and preprocessing
- Implementation of 10 classification algorithms
- Model evaluation and comparison
- Final model selection and hyperparameter tuning

**Algorithms:** Logistic Regression, K-Nearest Neighbors, Gaussian Naive Bayes, Decision Tree, Support Vector Machine, Random Forest, AdaBoost, Gradient Boosting, Bagging, and MLP Classifier.

**Evaluation metrics:** Accuracy, Precision, Recall, Weighted F1-score, Confusion Matrix, and ROC-AUC.

### 3. Clustering

Clustering techniques are used to identify customer groups based on purchasing behaviour in the Online Retail dataset.

The track includes:
- Data cleaning and RFM feature engineering
- Feature transformation and scaling
- K-Means Clustering
- Agglomerative Hierarchical Clustering
- Cluster evaluation and visualisation
- Customer cluster profiling

**Evaluation metrics:** Silhouette Score, Davies–Bouldin Index, and Calinski–Harabasz Index.

**Visualisations:** Elbow curve, dendrogram, PCA-based cluster plots, and t-SNE visualisation.
